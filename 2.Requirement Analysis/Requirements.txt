CUSTOMER JOURNEY:
Login -> Open FMS -> Enter Data -> Manage Farmers/Crops/Buyers -> Generate Reports -> View Dashboard -> Decision Making

FUNCTIONAL REQUIREMENTS:
- User Authentication
- Farm, Crop, Farmer and Buyer Management
- Data Validation
- Object Relationships
- Reports & Dashboards
- Role Management

NON-FUNCTIONAL:
Usability - Lightning UI
Security - profiles, roles and sharing rules
Reliability - cloud-based storage
Performance - fast access
Scalability - supports additional farms and users

DATA FLOW:
User -> Salesforce Lightning UI -> Custom Objects -> Validation & Relationships -> Reports -> Dashboards

TECH STACK:
Frontend: Salesforce Lightning UI | Platform: Salesforce | Database: Salesforce Cloud | Analytics: Reports & Dashboards
